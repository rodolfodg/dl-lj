COMO RODAR NO VS CODE
1. Extraia/abra esta pasta no VS Code.
2. Confirme que index.html, logo.png e banner.png estão na mesma pasta.
3. Abra index.html com o Live Server.
4. Se não tiver Live Server, abra o index.html diretamente no navegador.

O projeto usa Font Awesome por CDN para os ícones.
